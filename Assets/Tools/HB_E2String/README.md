# HB_E2String

`Enum.ToString()`, `Enum.Parse()`, `Enum.IsDefined()` 호출 시 발생하는 리플렉션·박싱(Boxing) 및 힙 할당을 제거하기 위한 Roslyn Source Generator(`EString.dll`) 및 에디터 관리 도구입니다.

---

## 📦 UPM 패키지 설치 (Installation)

```text
https://github.com/MoewMeowH/CustomUnityTools.git?path=Assets/Tools/HB_E2String
```

---

## 시작하기

1. 패키지를 설치합니다. `Plugins/EString.dll`이 `RoslynAnalyzer` 라벨로 들어 있어 별도 설정이 필요 없습니다.
2. `Tools > HB > E2String Manager`를 엽니다.
3. **1. 어트리뷰트 스크립트 상태**에서 생성 폴더를 정하고 **E2StringAttribute 스크립트 생성**을 누릅니다.
   - 어트리뷰트(`E2StringAttribute`)와 옵션(`E2StringOptions`)은 패키지에 들어 있지 않습니다. 서버와 공유하는 폴더 등 원하는 `Assets` 하위 위치에 직접 생성합니다.
   - 생성 폴더 기본값은 `Assets/Scripts/E2String`입니다. 경로를 직접 입력하거나 **폴더 선택...**으로 고르며, `Assets` 밖이면 생성하지 않습니다. 마지막으로 쓴 폴더는 프로젝트별로 기억합니다 (`EditorPrefs`, 키에 `PlayerSettings.productGUID` 포함).
   - 같은 이름의 파일이 이미 있으면 덮어쓸지 묻습니다.
   - **글로벌 + EString.Script 호환**(기본): 글로벌 네임스페이스와 `EString.Script` 양쪽에 어트리뷰트를 만듭니다. `using` 없이 바로 쓸 수 있습니다. `E2StringOptions`는 글로벌에 하나만 만들어 두 어트리뷰트가 같은 옵션 타입을 씁니다.
   - 체크를 해제하면 지정한 네임스페이스에만 만듭니다 (`E2StringOptions`도 그 네임스페이스 안). 비워두면 글로벌에만 만듭니다. 네임스페이스 이름이 식별자 규칙에 맞지 않거나 C# 키워드를 포함하면 생성하지 않습니다.
   - 폴더가 어떤 asmdef에도 속하지 않으면 `HB.E2String.Attributes.asmdef`를 함께 만듭니다. Assembly-CSharp는 자동으로 참조하고, asmdef 어셈블리에서는 references에 `HB.E2String.Attributes`를 추가하면 됩니다. 폴더 아래 다른 스크립트가 있으면 그 스크립트까지 새 어셈블리로 옮겨지므로 asmdef를 만들지 않습니다. asmdef에서도 쓰려면 전용 빈 폴더에 만드세요.
   - 이름이 `HB.E2String.Attributes`인 asmdef가 프로젝트에 이미 있어도 만들지 않습니다. 이때 어트리뷰트는 Assembly-CSharp에 들어갑니다.
   - 폴더가 이미 asmdef에 속하면 그 어셈블리에 들어갑니다. 어트리뷰트를 쓰는 asmdef가 그 어셈블리를 참조해야 합니다.
   - `.asmdef`는 Unity 전용 파일이라 서버와 `.cs`를 공유해도 영향이 없습니다.
4. Enum에 `[E2String]`을 붙이면 컴파일 시 `{Enum}Extensions` 클래스가 생성됩니다.

> 어트리뷰트가 Assembly-CSharp에 있으면(asmdef 없는 폴더) asmdef 어셈블리의 Enum에는 쓸 수 없습니다. 매니저가 어트리뷰트의 어셈블리를 보여주고 경고합니다.
>
> 이전 버전으로 생성한 `E2StringAttribute.cs`에는 `E2StringOptions`가 없습니다. 옵션을 쓰려면 매니저의 **다시 생성 (덮어쓰기)**로 같은 자리에 다시 만드세요. 네임스페이스 설정은 기존 파일에서 읽어 채우며, 매니저가 만든 파일(첫 줄 `// <auto-generated by HB E2String Manager />`)만 덮어씁니다.

## 옵션 (`E2StringOptions`)

어트리뷰트에 옵션을 넘겨 생성할 멤버를 고릅니다. 생략하면 `ParseExact`(문자열 변환만)입니다.

```csharp
[Flags]
public enum E2StringOptions
{
    ParseExact    = 0,       // ToStringFast, To{Enum}Fast(string) — 항상 생성
    IntConversion = 1 << 1,  // ToIntFast, To{Enum}Fast(int), IsDefinedFast (+ [Flags]면 IsValidFlagsFast)
    Collections   = 1 << 2,  // Values
    All           = ~0,
}
```

## 사용 예시

```csharp
[E2String]                                         // ParseExact: 문자열 변환만
public enum Region { Kr, Us }

[E2String(E2StringOptions.All)]
public enum CharacterState { Idle, Move, Attack, Die }

[E2String(E2StringOptions.IntConversion), System.Flags]
public enum Perm { None = 0, Read = 1, Write = 2, Exec = 4 }

// 1. Enum -> String (할당 없음)
string name  = CharacterState.Move.ToStringFast();          // "Move"
string bad   = ((CharacterState)9).ToStringFast();          // "not defined CharacterState"
string bad2  = ((CharacterState)9).ToStringFast("?");       // "?"

// 2. String -> Enum (정확히 일치)
CharacterState s1 = "Attack".ToCharacterStateFast();                         // Attack
CharacterState s2 = "attack".ToCharacterStateFast();                         // 대소문자가 달라 실패 → default (Idle)
CharacterState s3 = "Jump".ToCharacterStateFast(fallback: CharacterState.Idle); // 실패 시 fallback

// 3. Enum <-> int (IntConversion)
int  i  = CharacterState.Attack.ToIntFast();                 // 2
CharacterState s4 = 1.ToCharacterStateFast();                // 정의 검사 후 변환
bool ok = CharacterStateExtensions.IsDefinedFast(5);         // false

// 4. 값 순회 (Collections) — 배열을 for로 돌면 GC 0
var values = CharacterStateExtensions.Values;
for (int k = 0; k < values.Length; k++) { /* ... */ }

// [Flags]
string p  = (Perm.Read | Perm.Exec).ToStringFast();          // "Read, Exec" (조합마다 첫 호출에서만 할당 후 캐시)
Perm   q  = "Read, Exec".ToPermFast();                       // 조합 파싱
bool   vf = PermExtensions.IsValidFlagsFast(5);              // true
```

## 생성되는 멤버

클래스 이름은 `{바깥타입_}{Enum}Extensions`이며 Enum과 같은 네임스페이스에 생성됩니다 (예: 중첩 `Outer.MyEnum` → `Outer_MyEnumExtensions`).
Enum이 `internal`이면 클래스도 `internal`로 생성됩니다.

| 옵션 | 멤버 | 설명 |
|---|---|---|
| (항상) | `string ToStringFast(this T, string fallback = "not defined {Enum}")` | switch로 문자열 반환. 정의 밖 값이면 `fallback` |
| (항상) | `T To{Enum}Fast(this string?, T fallback = default)` | 이름이 대소문자까지 정확히 일치해야 함 (공백·숫자 문자열 불허) |
| IntConversion | `int ToIntFast(this T)` | Enum → int (명시적 캐스트) |
| IntConversion | `T To{Enum}Fast(this int, T fallback = default)` | 정의 검사 후 변환 (`[Flags]`는 조합 검사) |
| IntConversion | `static bool IsDefinedFast(T)` / `IsDefinedFast(int)` | 이름이 정의된 값인지 검사 |
| IntConversion | `static bool IsValidFlagsFast(T)` / `IsValidFlagsFast(int)` | `[Flags]` 전용. 정의된 플래그 조합인지 검사 (0 포함) |
| Collections | `static readonly T[] Values` | 값 (선언 순서, 별칭 포함) |

### 동작 규칙

- **기본 형식**: `byte` ~ `ulong` 모두 지원합니다. int 범위를 벗어난 멤버가 있으면 `IntConversion`일 때 경고 `E2S003`이 뜨며, int API는 그 멤버를 다루지 못합니다.
- **같은 값의 별칭**(`A = 1, B = 1`): `ToStringFast`는 먼저 선언된 이름을 반환하고, 문자열 파싱은 두 이름 모두 받습니다.
- **`[Flags]`**: 조합 값을 `"A, B"` 형식으로 출력·파싱합니다. 정의된 플래그로 표현할 수 없는 값은 `fallback`이 됩니다.
- **키워드 멤버**: `@class` 같은 멤버는 `"class"`로 출력·파싱합니다.

### 생성하지 않는 경우 (경고)

| ID | 상황 |
|---|---|
| `E2S001` | 제네릭 타입(`Outer<T>`) 안의 Enum |
| `E2S002` | Enum 또는 바깥 타입이 `private` · `protected` |
| `E2S004` | 생성 클래스 이름이 같은 네임스페이스에서 겹침 (예: 최상위 `Outer_E`와 중첩 `Outer.E`) |

### 생성하지만 경고하는 경우

| ID | 상황 |
|---|---|
| `E2S003` | `IntConversion`인데 int 범위를 벗어난 멤버가 있음 |
| `E2S005` | 같은 네임스페이스에 이름이 같은 Enum이 있음 (예: `Outer1.State`, `Outer2.State`). `"x".ToStateFast()`가 모호하므로 `Outer1_StateExtensions.ToStateFast("x")`처럼 정적 호출로 씁니다 |

## 에디터 매니저 윈도우 (`Tools > HB > E2String Manager`)

- **Scan / Refresh** (툴바): 어트리뷰트 검사와 Enum 스캔을 다시 합니다. 자동 스캔은 창을 처음 열 때만 하며, 결과는 도메인 리로드 뒤에도 유지됩니다.
- **어트리뷰트 스크립트 상태**: 프로젝트에 `E2StringAttribute` 정의가 있는지 확인하고, 없으면 원하는 위치에 생성합니다.
  - 찾는 순서: 파일 이름이 `E2StringAttribute`인 스크립트(패키지 포함) → 없으면 `Assets` 아래 모든 `.cs`(경로에 `/Editor/`가 있는 파일 제외). 주석·문자열을 뺀 코드에 `class E2StringAttribute` 선언이 있어야 합니다.
  - 있으면 위치와 어셈블리 이름을 보여줍니다. Assembly-CSharp면 asmdef에서 쓸 수 없다고 경고하고, asmdef 어셈블리면 references에 넣을 이름을 안내합니다.
  - **스크립트 파일 열기** · **프로젝트 위치 표시**: 어트리뷰트 파일을 열거나 Project 창에서 Ping합니다.
  - **다시 생성 (덮어쓰기)** (접기): 같은 자리에 새 내용으로 다시 만듭니다. 매니저가 만든 파일이 아니면 안내만 보이고 덮어쓰지 않습니다.
- **E2String 적용 Enum 목록**: `[E2String]`이 붙은 Enum과 멤버, 선언 위치를 보여줍니다.
  - **검색**: 타입 이름 · 네임스페이스 · 파일 경로로 거릅니다 (대소문자 무시).
  - 항목마다 타입 이름(중첩이면 `Outer.MyEnum`) · 네임스페이스(없으면 `Global`) · `파일:줄` · 멤버 목록(80자까지)을 보여줍니다.
  - **스크립트 열기**: Enum 선언 줄로 엽니다. **위치 표시**: Project 창에서 Ping합니다.
  - **호출 복사**: 해당 Enum의 옵션에 맞는 호출 예시 코드를 클립보드에 복사합니다. `IntConversion`이면 int 변환 · `IsDefinedFast`(`[Flags]`면 `IsValidFlagsFast`도), `Collections`면 `Values`가 들어갑니다.
- **Guide & Cheatsheet** (툴바 토글): 생성되는 확장 메서드 요약을 보여줍니다.

## 성능 (Unity 7 IL2CPP · Windows x64 · 100개 멤버 Enum · 호출 1회 기준)

| | 기존 | E2String |
|---|---|---|
| Enum → String | `ToString()` 43.4 ns | `ToStringFast()` 11.0 ns |
| String → Enum | `Enum.TryParse` 727 ns | `To{Enum}Fast(string)` 16.3 ns |
| 정의 검사 | `Enum.IsDefined` 134 ns / 20 B | `IsDefinedFast` 0.7 ns / 0 B |
| 전체 값 순회 (원소당) | `Enum.GetValues` 168 ns / 44.6 B | `Values` 0.7 ns / 0 B |

시간은 Release, 할당은 Development 플레이어 기준입니다. IL2CPP에서는 `ToString()` · `Enum.TryParse`도 할당하지 않으므로 이득은 주로 속도입니다.
비용은 Enum(100 멤버) 하나당 `GameAssembly.dll` 약 +11 KB입니다 (IL2CPP, Managed Stripping `Low`). `Medium` 이상에서는 쓰지 않는 Enum의 생성 코드가 빠집니다. 빌드 크기 상세와 측정 방법은 [벤치마크 리포트](https://github.com/MoewMeowH/CustomUnityTools/blob/main/Assets/Tools/Benchmarks/E2String/Benchmark.md)를 참고하세요.

## 주의 사항

- 문자열 → Enum 변환은 대소문자를 구분합니다. 대소문자 무시 파싱은 벤치마크에서 기본 API보다 이득이 없어 제공하지 않습니다.
- `[Flags]` 조합 문자열 캐시는 프로세스가 끝날 때까지 유지됩니다. 서로 다른 조합 값이 아주 많이 생기는 용도라면 메모리를 확인하세요.
- `Values`는 배열이라 외부에서 내용을 바꿀 수 있습니다. 수정하지 마세요.
- 서로 다른 네임스페이스의 같은 이름 Enum을 한 파일에서 둘 다 `using`하면 `To{Enum}Fast` 확장 호출이 모호해집니다 (생성기가 알 수 없어 경고하지 않음). 정적 호출로 쓰세요.
- 매니저의 Enum 목록·호출 복사는 소스 텍스트를 스캔해 옵션을 판단합니다. `E2String(...)` 괄호 안만 보며(같은 대괄호의 다른 어트리뷰트 인자는 보지 않음), `(E2StringOptions)6`처럼 숫자로 지정한 옵션은 인식하지 않습니다 (코드 생성에는 영향 없음).
- 스캔은 `class` · `struct` · `interface` · `record`(`record class/struct` 포함)를 바깥 타입으로, `namespace X { }`와 파일 범위 `namespace X;`를 네임스페이스로 인식합니다.
- 매니저의 Enum 목록은 `Assets` 아래만 스캔하며, 생성기가 거절한 Enum(`E2S001`·`E2S002`)도 보일 수 있습니다. 실제 생성 여부는 콘솔 경고로 확인하세요.
- 스캔은 주석 · 문자열 · 전처리 지시문 줄만 지우고 정규식으로 찾습니다. `#if`로 꺼진 구간의 Enum도 목록에 보일 수 있습니다. `'.'`으로 시작하거나 `~`로 끝나는 폴더와 파일 이름이 `E2StringAttribute.cs`인 파일은 스캔하지 않습니다.
