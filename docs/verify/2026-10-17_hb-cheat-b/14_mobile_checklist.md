# 14 모바일 실기기 순서표 (이번에는 실행하지 않음 — 사용자 결정)

출처: [B 계획서](../../plans/2026-10-17_hb-cheat-remaining-checks.md) 결정. 13에서 미확인으로 넘긴 **터치**를 포함한다.

## 장비
- Android 실기기 1대 이상 (노치·펀치홀 화면 권장), USB 디버깅 켬, `adb` 연결 확인.
- iOS 실기기 1대 (노치 기종 권장), Xcode가 있는 Mac, 개발자 서명.
- 한글 OS 키보드(기기 기본 + 서드파티 1종 권장).

## 빌드 설정
- 테스트 프로젝트(ToolTest6.3 또는 전용 프로젝트)에 com.hb.cheat 설치 (전체 해시 고정), 디파인 `HB_CHEAT;DEV_CHEAT`를 대상 플랫폼(Android/iOS)에 켬.
- **Development Build 켬** (꺼져 있으면 릴리즈로 보고 HB_Cheat 빌드 가드가 빌드를 막음 — 6장 3.4).
- 샘플(Cheat Examples) Import, 문자열 인자가 있는 치트 포함 (`actor.nickname` 등).
- 독립 패널(CHEAT 버튼) 확인용: Prefer Console Tab 끔 + Generate Registry (B 13 결함 참고). 콘솔 탭 모드도 따로 한 번.
- 화면 방향: 세로·가로 각각.
- 한글 표시용 PanelSettings(한글 폰트 포함)를 `CheatSystem.Options.PanelSettings`에 지정한 빌드와, 지정하지 않은 기본 빌드(내장 폰트 + OS 폴백) 두 가지.

## 확인 항목과 통과 기준 (실행 전에 고정, 결과를 보고 바꾸지 않음)
| # | 항목 | 조작 (사람) | 통과 기준 |
|---|---|---|---|
| M1 | 터치: CHEAT 버튼 탭 | 손가락으로 탭 | 패널 열림. 탭으로 드래그가 일어나지 않음 |
| M2 | 터치: CHEAT 버튼 드래그 | 짧게(12px 이상)·길게·화면 끝 밖으로 | 손가락을 따라 움직이고, 놓은 자리에 남고, 화면(안전 영역 포함) 밖으로 나가지 않음. 드래그 뒤 패널이 열리지 않음 |
| M3 | 터치: 패널 안 치트 실행 | 로컬 치트 탭 | 실행됨 (History에 기록) |
| M4 | 키보드 인셋 | 검색창·문자열 인자 입력란을 탭해 OS 키보드를 올림 | 입력란이 키보드에 가려지지 않음 (패널이 키보드 높이만큼 올라가거나 줄어듦). 키보드를 내리면 원래대로 |
| M5 | 안전 영역 (노치) | 세로·가로에서 패널과 CHEAT 버튼 위치 확인 | 패널 내용과 버튼이 노치·펀치홀·홈 인디케이터 영역에 가려지지 않음 |
| M6 | 한글 폰트 | 한글 이름 치트·설명·History 보기 | 두 빌드(한글 PanelSettings / 기본)에서 한글이 깨지지 않거나, 기본 빌드에서 깨지면 README 안내대로 PanelSettings 지정으로 해결됨 |
| M7 | 검색창 입력 | 한글·영문으로 검색 | 입력이 반영되고 목록이 걸러짐. 한글 조합 중 글자가 사라지거나 두 번 들어가지 않음 |
| M8 | 문자열 인자 입력 | `actor.nickname` 등에 한글·공백·특수문자 입력 후 실행 | 입력한 문자열 그대로 실행 결과에 나옴 |

## 기록
- 기기 모델, OS 버전, 화면 해상도·안전 영역 값, 빌드 설정, 항목별 결과와 스크린샷(관찰 보조).
- 사람 조작은 "사람 조작"으로 표시. 코드 호출로 대신한 것은 "대체 확인"으로 표시하고 원래 항목은 미확인.
